# 待ち方（区間 D・E）

待ちの間に中身の無いターンを重ねると、文脈だけが増えて進捗は無い。完了通知を待つ。

- 長いコマンド（一括検証・E2E・Sonar・CI 待ち）は Bash の `run_in_background` で起動し、完了通知を待つ。`ScheduleWakeup`・`ReadNotifications`・`sleep` によるポーリングや、中身の無い「待っています」ターンを挟まない。Monitor は使わない。
- サブエージェントの完了も通知を待つ。並行で起動したときはバックグラウンドで起動し、通知で受ける。
- 出力はファイルにリダイレクトし、文脈には要約行（`tail` の数行・exit code）だけを入れる。
- ワーカーが `run_in_background` を使ってよいのは、検証コマンド（書込を伴わないもの）だけ。書込を伴うコマンドは前景で実行する。バックグラウンドの Bash は、書込ガードの事後照合が効かないため。
