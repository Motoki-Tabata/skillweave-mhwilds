## 0. 前提

- 火力は物理の期待値と内訳（攻撃力・会心率・会心倍率）。`packages/solver` の `evaluateDamage` で計算する。属性は含めない（decisions.md Q43）。
- 発動条件はマスターの `conditions`（現行 21 件）。名前は ja の辞書の `name`。トグルの既定はすべてオフで、状態は保存しない（Q44）。
- 表示中の構成の火力は、検索したときの武器と発動条件で固定する。検索の後にトグルや武器を変えても、表示は変わらず、次の検索から効く（Q44）。
- スキルの説明文は ja の辞書の `levelDescriptions`。改行（`\r\n`・`\n`）を保って表示する（`white-space: pre-line`。`\r\n` は `\n` にそろえる）。説明文の数字は全角のまま出す。
- 補完は、そのレベルの `effectsByLevel` の効果から画面で作る文（4 節）。辞書には保存しない。
- 数値（期待値・攻撃力・会心率・会心倍率・Lv・補完の数値・件数）は Inter と `tabular-nums` にする。
- 文字サイズは MASTER.md の Type Scale の4つ（12・14・16・20px）だけを使う。
- 007 で新しく作る部品はすべて既存の生成物（Card・Checkbox・Label・Button・RadioGroup）と lucide のアイコンで作る。shadcn-vue の部品は足さない。

### 2.7 キーボード・フォーカス・読み上げ

- 発動条件のトグルは、Tab で移動し Space で切り替える（Checkbox）。`<fieldset>` に `aria-label="発動条件"` を付ける。
- スキルの効果の開閉ボタンは、Enter・Space で開閉する。`aria-expanded` と、一覧の `id` を指す `aria-controls` を持つ。
- フォーカスリングを消さない。オンのトグルを色だけで示さない（チェックの印を併記する）。

## 3. D2 スキルを選ぶダイアログ

### 3.1 変更点

```
[攻撃                         選択中][ⓘ]   ← トグルボタン ＋ 説明の開閉ボタン
┌ 攻撃（最大 Lv5） ─────────────────────┐
│ Lv1  基礎攻撃力＋３                              │
│      効果: 攻撃力 +3                             │
│ …                                                │
│ Lv5  攻撃力を１．０４倍し、                      │
│      基礎攻撃力＋９                              │
│      効果: 攻撃力 ×1.04・攻撃力 +9               │
└──────────────────────────────┘
[見切り                             ][ⓘ]
```

| 項目 | 部品 | 既定 | 入力規則・動作 |
|---|---|---|---|
| スキルの一覧の格子 | 004 のトグルボタンの格子の列数を、基準幅で1列、`md` で2列、`lg` で3列にする（説明の開閉ボタンを足すと、基準幅の2列ではスキル名の幅が足りないため） | — | トグルボタンの見た目と動作（押すと追加・もう一度押すと外す・「選択中」の表示）は 004 のまま |
| 説明の開閉ボタン | 各トグルボタンの右に置くアイコンボタン（44×44px・ghost・lucide の `Info`）。`aria-label="<スキル名>の説明"`・`aria-expanded`・`aria-controls`。開いているときは押された見た目（`--muted` の背景）にする | 閉じる | 押すと、そのスキルの説明の領域を開閉する。同時に開くのは1つだけで、別のスキルの説明を開くと前のものを閉じる。タブを切り替えたとき・検索欄の語を変えたとき・ダイアログを閉じたときは閉じる |
| 説明の領域 | トグルボタンの行の直下に、格子の幅いっぱい（全列にまたがる）で出す。1px の枠（`--border`）・一段上の面（`--muted`）・角丸 4px・内側余白 12px。先頭に「<スキル名>（最大 Lv<n>）」（14px・太字）。続けて `<dl>` でレベルごとに、`dt` に「Lv<n>」（12px・Inter・幅 32px）、`dd` にそのレベルの説明文（12px・改行を保つ）と補完（12px・補助の文字色・「効果: 」で始める） | — | Lv1 から最大レベルまで並べる。説明文が無いレベルは補完だけ、効果が無いレベルは説明文だけを出す。どちらも無いレベルは行ごと出さない。出すレベルが1つも無いときは「このスキルの説明はありません。」（12px） |

- 検索欄に語があるとき（すべての種類から絞り込む表示）も同じ部品にする。
- 説明の領域は、開閉ボタンの `aria-controls` が指す `id` を持ち、`<section aria-label="<スキル名>の説明">` で書く。
- フッター（選択中のスキル・閉じる）は 004 のまま。

### 3.3 キーボード・フォーカス

- Tab の順は、トグルボタン → 説明の開閉ボタン → （開いていれば）説明の領域を飛ばして次のトグルボタン。説明の領域はフォーカスを持たない（読むだけ）。
- 説明の開閉ボタンは Enter・Space で開閉する。開閉してもフォーカスはボタンに残す。

## 4. 補完の文の書式

そのレベルの `effectsByLevel` の効果をすべて使い、「効果: 」の後に次の書式で並べる（decisions.md Q45）。

| `stat` | 書式 | 例 |
|---|---|---|
| `attack_add` | 攻撃力 <符号><値> | 攻撃力 +9 |
| `attack_mul` | 攻撃力 ×<値（小数第2位）> | 攻撃力 ×1.04 |
| `affinity_add` | 会心率 <符号><値>% | 会心率 +20% |
| `crit_mul` | 会心倍率 <値（小数第2位）> | 会心倍率 1.40 |
| `element_add` | 属性値 <符号><値> | 属性値 +50 |
| `element_mul` | 属性値 ×<値（小数第2位）> | 属性値 ×1.10 |

- 符号は、正の値に `+`、負の値に半角の `-` を付ける。加算の値は丸めずに出す。数値は Inter・`tabular-nums`。
- 発動条件の同じ効果を1つの組にまとめ、組の中は「・」でつなぎ、条件付きの組は末尾に「（<条件の名前>）」を付ける。組と組は「 ／ 」でつなぐ。組の並びは `effectsByLevel` の中で最初に出た順。
  - 例（攻撃 Lv5）: 「効果: 攻撃力 ×1.04・攻撃力 +9」
  - 例（弱点特効 Lv5）: 「効果: 会心率 +30%（有効部位への攻撃） ／ 会心率 +20%（傷口への攻撃）」
  - 例（挑戦者 Lv5）: 「効果: 攻撃力 +20・会心率 +15%（挑戦者の発動中）」
- 効果が無いレベル（火力に関係しないスキルを含む）は補完を出さない。
- 属性値の効果は、火力の計算には数えないが（Q40）、補完には出す（そのレベルの効果をすべて使うため）。現行のマスターには属性値の効果は無い。
