## 0. 前提

- 逆引きは、検索画面の条件をそのまま使い、護石だけを抽選テーブルから出うる仮想の護石に置き換えて解く（AC-1・Q167）。使う条件は、武器・必須スキル・候補にするランク・部位の固定・除外。使わない条件は、目的・件数・「護石」カード（登録した鑑定護石・生産護石を候補に含める）。発動条件は構成の解き方には効かず、構成カードの火力の表示にだけ使う（通常の検索と同じ）。
- 逆引きと通常の検索は、同じ結果パネルを使う。結果パネルには、最後に実行したほうの結果だけを出す。片方の実行中にもう片方を始めると、実行中のほうを打ち切る（004 の 3.5 の「検索し直す」と同じ扱い）。
- 候補は最大 10 件（件数の入力欄は使わない。Q169）。並びは AC-5 の順で、画面では並べ替えない。
- 抽選の出やすさ（確率）は示さない（スコープ外）。
- 候補の構成は保存しない（スコープ外）。逆引きの結果のカードに「保存」は出さない。
- 新しい画面・ダイアログ・遷移・ui 部品の追加は無い。

## 2. S1 検索画面（変更）

### 2.1 検索操作（`SearchActions`）

004 の 3.2.4 の「検索」の行の下に、逆引きの行を足す。

```
[検索できない理由（12px。あるときだけ）]
[ 検索（primary・flex-1） ][ キャンセル（outline。実行中だけ） ]
[ 護石を逆引き（outline・幅いっぱい） ]
[逆引きの説明（12px）／逆引きできない理由（12px）]
```

| 部品 | 内容 |
|---|---|
| 「護石を逆引き」ボタン | Button（outline・幅いっぱい・高さ 40px。`type="button"`）。押すと逆引きを始める。逆引きの実行中はラベルを「逆引きし直す」に変え、有効のままにする |
| 逆引きの説明 | ボタンの直下に補助文（12px・`--muted-foreground`）。「登録した護石の代わりに、抽選テーブルから出うる護石で組めるかを調べます。目的・件数・護石の条件は使いません。」。`aria-describedby` でボタンに関連づける |
| 逆引きできない理由 | 逆引きできないあいだは、説明の代わりに理由（12px）を出し、`aria-describedby` でボタンに関連づけ、ボタンを無効（`disabled`）にする。複数あてはまるときは上のものを出す。1) 検索できない理由（武器が未選択・ランクが0個）があるとき: その理由の文言を「…と逆引きできます。」に置き換えたもの（「武器を選ぶと逆引きできます。」「候補にするランクを選ぶと逆引きできます。」） 2) どのレア度の抽選テーブルも無いとき（AC-8）: 「抽選テーブルが未整備のため、逆引きできません。」 |
| 「キャンセル」 | 通常の検索・逆引きのどちらの実行中にも出し、実行中のほうを取り消す |

- 主要ボタン（primary）は「検索」のままにする（MASTER.md の Buttons。1画面に1つ）。
- 入力欄で Enter を押したときの送信は、通常の検索だけを始める（逆引きは始めない）。
- 必須スキルが0件でも逆引きできる（通常の検索と同じ。候補は「任意」の枠だけの護石になる）。

### 2.2 結果パネルの見出し

- h2 の文言を、最後に実行したほうに合わせて変える: 通常の検索は「検索結果」、逆引きは「逆引きの結果」。未実行（Q0）は「検索結果」。
- 逆引きを始めたときも、結果パネルの h2 にフォーカスを移す（004 の 3.7 と同じ）。

### 2.5 逆引きの条件の要約

R1（候補あり）・R2・R4 で、候補のカードの上に1行（12px・折り返し可）を出す。通常の検索の要約（004・020・021）とは別の文にし、使わない条件（目的・件数・鑑定護石・生産護石）を入れない。

「武器: <名前> ／ 必須スキル <n> 件 ／ 発動条件: <名前・…|なし> ／ <固定 n 部位|固定なし> ／ <除外: 防具 n 件・装飾品 n 件|除外なし> ／ 抽選テーブル: レア<r>・レア<r>・…」

- 「抽選テーブル」には、テーブルがあって候補にしたレア度を昇順で並べる（AC-8。テーブルの無いレア度は出さない）。

### 2.7 キーボード・フォーカス・読み上げ

- 「護石を逆引き」は Tab で「検索」（と「キャンセル」）の次に到達する。Space・Enter で押せる。
- 逆引きを始めたとき、結果パネルの h2（「逆引きの結果」）にフォーカスを移す。
- 進捗の更新は `<output aria-live="polite">` で読み上げる。
- 「任意」は色だけでなく文言と破線で示す。
- 逆引きできない理由は `aria-describedby` でボタンに関連づける。
