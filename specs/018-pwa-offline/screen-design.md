## 新しい版の通知（全画面・AC-8・AC-9）

### 置き場
画面の右上の、トーストと同じ置き場（`AppToaster` の `ToastViewport`。ヘッダーの下・右端）に出す。トーストと同じ並びに入り、トーストと重ならない。

- 置き場を新しく作らず、利用者が「通知はここに出る」と覚えている位置に揃えるため。
- 作業領域を押し下げない（帯にすると、表示した瞬間に画面の内容がずれる）。

### 部品
トーストと同じ面（`--card` の面・`--border` の 1px の枠・角丸）の上に、次を置く。新しい部品は作らない。

| 要素 | 部品・文字の大きさ | 文言 |
|---|---|---|
| 見出し | `ToastTitle`。基準・500 | 新しい版があります |
| 本文 | `ToastDescription`。補助テキスト・`--muted-foreground` | 再読み込みすると新しい版に切り替わります。保存していない入力は消えます。 |
| 再読み込みの操作 | Button `outline`（高さ 40px）。本文の下・左寄せ | 再読み込み |
| 閉じる | Button `ghost` のアイコンボタン（44×44px・lucide `X`）。右上の角 | `aria-label`・`title`: 通知を閉じる |

- 再読み込みのボタンは `outline` にする（主要ボタンは1画面に1つで、各画面の主要ボタン（「検索」など）と競わせない）。
- 幅はトーストの置き場と同じ（今の `ToastViewport` の幅 320px。画面の幅から 32px を引いた幅を超えない）。最小対応幅での1行の合計: 見出しの 14px×9 字 ≈ 126px ＋ 閉じるボタン 44px で収まる。本文は折り返す。再読み込みのボタンは「再読み込み」5字 ≈ 70px ＋ 左右の余白 32px ≈ 102px で、本文とは別の行に置くので切り詰めない。

### 状態と振る舞い
| 状態 | 表示 |
|---|---|
| 新しい版が無い・事前キャッシュの途中・失敗 | 出さない |
| 新しい版が事前キャッシュを取り終えた | 出す。自動では消さない（トーストの表示時間を当てない） |
| 再読み込みを押した直後 | ボタンを無効にし、ラベルを「再読み込み中…」にする（二重の操作を防ぐ）。画面が読み込み直されるまでこのまま |
| 閉じるを押した・Escape・スワイプ | この画面からは消す。次にアプリを開いたとき（再読み込み・別のタブ・アプリの起動）に、新しい版がまだ待っていればまた出す |

- 読み上げ: `role="status"`（丁寧な通知・`ToastRoot` の `type="background"`）。フォーカスは移さない。ToastViewport の既定のホットキー（F8）で通知へ移れる。
- 開いている画面が複数あるときは、それぞれに出す。どれか1つで再読み込みを押すと、すべての画面が新しい版で読み込み直される（AC-9）。押していない画面の通知は、読み込み直されて消える。
- 通知が出ていても、今の画面の操作はそのまま続けられる（モーダルにしない）。
- 普通のトーストと同時に出たときは、出た順に上から縦に積む（間隔はトーストどうしと同じ 8px）。通知を特別に上へ固定しない。

## プライバシー（`/privacy`・AC-12）

### 画面構成
節の並び・見出し・部品は今の画面のままにする。変えるのは「この端末に保存するデータ」の節の文面と、最終更新日だけ。

### 項目定義（表記の文面）
**この端末に保存するデータ**

装備検索の計算はブラウザ内で行います。次のデータはこの端末に保存します。

- 護石と個体差のある武器の下書き
- テーマの設定
- ログイン後に戻る画面
- オフラインで使うための、画面のファイル・マスターデータ・画像から読み取る機能のファイル・Web フォント

下書きは、ログインして取り込むとサーバーへ送られます。サーバーから取得した護石・構成などのデータは、オフラインで使うためには保存しません。

- 「画像から読み取る機能」は、画面の操作名「画像から読み取る」に揃えた言い方（OCR とは書かない）。
- 画像から読み取る機能のファイルは、その機能を初めて使ったときに保存する（AC-5）。表記ではその時期を書かない（保存するものを列挙する節のため）。

**最終更新日**

形式は `YYYY/MM/DD`。値は文面を変えた日にする（実装のときに決める）。

## アプリのアイコンとマニフェスト（AC-1）

### アイコンの図案
公式の画像・アイコンを使わない自作の図案（憲法・decisions.md Q181）。方向性「鍛冶場の鉄」に合わせ、文字を入れない。

- 地: 正方形の全面を `--background`（ダーク）の鉄灰で塗る。角丸・影・グラデーションは付けない（角の丸めは OS に任せる）。
- 印: 縦の3本の帯（`--primary`（ダーク）の橙）と横の3本の帯（`--muted-foreground`（ダーク）の灰）を、交点ごとに上下を入れ替えて織った格子（市松に上下が替わる）。上になる帯の両側に地の色の細い隙間を入れ、織り目を見せる。サイト名の「Weave」（織る）とスキルを組み合わせることを表す。
- 帯の太さは印の一辺の 1/9、隙間は帯の太さの約 0.3 倍にする。帯の中心は印の一辺を 9 としたとき 2・4.5・7 の位置に置き、帯は印の端から端まで通す。
- 縦横2本ずつの案（帯の太さ 1/7）と比べたうえで、織り目が布らしく読める3本ずつに決めた（ゲート B-1）。ファビコンの 16px では隙間が潰れて格子に見えるが、それでよい。
- 印の置き方:
  - 通常（`purpose: any`）: 印の一辺を全体の約 62% にして中央に置く。
  - maskable（`purpose: maskable`）: 印をセーフゾーン（中心から半径 40% の円）の内側に収める（一辺を全体の約 50% にして中央に置く）。
- 原図は SVG で1つ作り、PNG（192px・512px・maskable の 512px）はそこから作る（作り方は区間 C）。ファビコンにはその SVG を使う。

### マニフェストの項目
| 項目 | 値 |
|---|---|
| `name` | SkillWeave（非公式の二次創作） |
| `short_name` | SkillWeave |
| `lang` | `ja` |
| `start_url`・`scope` | `/` |
| `display` | `standalone` |
| `theme_color`・`background_color` | `--background`（ダーク）の HEX の参考値 |
| `icons` | 192px と 512px の PNG（`any`）、512px の PNG（`maskable`） |

- `name` に「非公式の二次創作」を含め、インストールの確認や OS のアプリ一覧でも二次創作である旨が見えるようにする（憲法）。
- テーマの色はダークに固定する。ライトのテーマに切り替えても `theme-color` は変えない（既定がダークで、切り替えに追従させるのはスコープ外）。

### `index.html` の参照
- `<link rel="manifest">`・`<meta name="theme-color">`（マニフェストと同じ値）・`<link rel="icon">`（SVG）・`<link rel="apple-touch-icon">`（192px の PNG）を足す。
