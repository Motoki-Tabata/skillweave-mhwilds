# 019 damage-solve-perf の決定記録

## Q41（決定: 2026-10-24）
- 問い（`open-questions.md` からの移設）: `expectedDamage` の検索時間が基準の 3 秒を超えた（006 の測定。実データ・件数 10・必須スキル 3 個・解ありで最大 54974.3 ms。`design/tech-stack.md`「HiGHS の expectedDamage の測定（006 damage-model）」）。原因は、1件ごとに 2 段で解くことと、会心倍率×会心率ビットの積の線形化の緩和が弱いこと（solver-agent の推定。未切り分け）。対策の案: 装飾品の候補の絞り込み、会心率ビットの粗い離散化、2 段目の省略、件数の既定を下げる、Worker 上での非同期の表示（仮: `packages/solver` だけを触る独立した機能として `/tsod-discover` で機能マップに追加し［019 damage-solve-perf として追加済み］、その機能の区間 A で対策を決める。007 damage-ui の区間 B はその機能のマージの後に始める［007 decisions.md Q42］。同じ機能で、006 のゲート D-1 のレビューの決定として次の2点も扱う: 2 段目の求解が解なしのとき 1 段目の解を返す縮退を入れる、実データのテスト（`packages/solver/src/test/solveBuilds.real.spec.ts`）の `timeoutMs` を明示する）
- 決定:
  - 厳密さは 006 の Q36 のまま保つ（期待値の最大から順に返す。近似で候補を絞ってから並べ替える方式は採らない）。求解の方式（定式化の作り直し・HiGHS の設定・2 段目の扱い）は区間 C で試作し、実データで測って決める。
  - 合格基準は 006 と同じ測定条件（実データ・条件をすべて有効・マスターの先頭の武器・護石なし・件数 10・必須スキル 3／6／10 個 × 解あり／解なし・各 3 回・Node）で、検索1回の合計時間の最大が 3 秒以下。結果は `design/tech-stack.md` に記録し、CI では測らない。
  - 厳密な方式で合計時間が 3 秒に届かないときは、基準を「1件目が求まるまでの時間の最大が 3 秒以下」に読み替える。そのときは、求めた構成を 1 件ずつ呼び出し側へ渡せるよう、ソルバーの進捗の通知に構成を載せる（画面の逐次表示は 007）。1件目までも 3 秒を超えるときは、対策を新しい Q として起票し、019 はその記録をもって閉じてよい。
  - `expectedDamage` のときだけ、支配される防具と装飾品を候補から外してよい（使うかは区間 C の測定で決める）。支配の定義は、同じ部位（装飾品は同じ種別）で、必須スキルと期待値に寄与するスキルのレベル・スロット・シリーズ／グループがすべて別の候補以下であること。1件目の期待値の最大は変わらないが、2件目以降に「同じ期待値で劣る防具を使う構成」は並ばなくなる。他の目的関数の候補と結果は変えない。
  - 006 のゲート D-1 の決定の2点も扱う: 2 段目の求解が解なしのときは例外にせず 1 段目の解を返す。実データのテストの `timeoutMs` を明示する。
- 判断材料（2026-10-24 に区間 A で切り分け。実データ・必須スキル 3 個・解あり・1 件目の 1 段目）:
  - 1 回の求解は約 4.2 秒で、分枝のノード数は 20、LP 緩和だけなら 6 ms。時間の大半は分枝ではなく HiGHS の根ノードの処理（presolve・再始動など）に使われている。LP 緩和の値は 289.7 で、整数解の 192.85 より約 50% 大きい（緩和が弱い）。
  - 1 段目と 2 段目はどちらも 1 回 1.7〜4.6 秒で、2 段目を省いても合計は半分程度にしかならない。
  - HiGHS の設定: `presolve` を `off` で約 1.1 秒、`mip_allow_restart` を `false` で約 1.6 秒。`mip_rel_gap` を 1e-4・1e-3 に緩めても、対称性の検出・ヒューリスティックを止めても、ほぼ変わらない。
  - 期待値の列を足さない基本の ILP（空き Lv の重み）は 43 ms。重いのは期待値の拡張の部分。
  - 防具の候補は全ランクで 714、上位だけで 582（上位だけにしても約 3.8 秒）。支配される防具を除くと各部位の候補が約半分（例: 頭 164 → 85）。
  - 対象のスキル 22・レベルの変数 107・会心倍率の候補 6（1.25 と 1.28〜1.4）・`attack_mul` を持つスキル 4・装飾品の候補 64。
- 採らなかった案: 近似を許す案（Q36 を変える）は、1件目が真の最大である保証を失うため採らない。件数の既定を下げる案は、1 回の求解が 1 秒を超える現状では件数を下げても届かないため、未達のときの扱いにも採らない。
