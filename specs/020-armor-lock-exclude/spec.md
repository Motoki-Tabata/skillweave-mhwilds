# 020: armor-lock-exclude

## 目的 / ユーザーストーリー
プレイヤーとして、検索画面で「頭はこの防具にする」「腰は何も付けない」のように部位を固定し、持っていない・使いたくない防具や装飾品を候補から外したうえで、必須スキルを満たす構成を探したい。固定と除外はその場の検索の条件として入力できればよく、再読み込みの後まで残さなくてよい。

用語:
- 部位の固定: 部位（頭・胴・腕・腰・脚）ごとに、使う防具を1つに決めるか、「何も付けない」にすること。ソルバーの `SolverRequest.fixedArmor`（null は何も付けない）に当たる。
- 除外: 指定した防具・装飾品を、ソルバーの候補から外すこと。防具は `SolverRequest.excludedArmorIds`、装飾品は 020 で足す `SolverRequest.excludedDecorationIds` に当たる。
- ランクの絞り込み: 004 で入れた「候補にするランク」（004 decisions.md Q21）。`apps/web` のアダプタが、選んでいないランクの防具を `excludedArmorIds` に入れて実装している。

## 受入基準（EARS記法）
- AC-1: THE system SHALL `packages/solver` の `SolverRequest` に `excludedDecorationIds?: DecorationId[]` を足し、指定された装飾品を求解の候補に含めず、返すどの構成にもその装飾品を使ってはならない（decisions.md Q79）。
- AC-2: IF `excludedDecorationIds` にマスターに無い ID が含まれるとき THEN システムは、求解の前に要求を不正（`InvalidRequestError`）として弾かなければならない。`excludedDecorationIds` を省略した要求と空の要求の結果は、020 の前と変えてはならない。
- AC-3: THE system SHALL 検索画面の検索条件に「部位の固定」の入力を置き、部位ごとに「固定しない」（既定）・その部位の防具のどれか1つ・「何も付けない」から選べるようにし、検索の実行で選んだ内容を `fixedArmor` に渡さなければならない（decisions.md Q82）。
- AC-4: WHEN 部位の固定で防具を選ぶとき THE system SHALL 候補にするランクの選択にかかわらず、その部位の全ランクの防具を選べるようにし、固定した防具をランクの絞り込みによる除外の対象から外さなければならない（decisions.md Q80）。
- AC-5: THE system SHALL 検索画面の検索条件に「除外」の入力を置き、防具と装飾品を名前で探して除外の一覧に足し、一覧から1件ずつ外せるようにしなければならない（decisions.md Q82）。
- AC-6: WHEN 除外の一覧に防具か装飾品があるまま検索を実行したとき THE system SHALL 除外した防具をランクの絞り込みによる除外とあわせて `excludedArmorIds` に、除外した装飾品を `excludedDecorationIds` に渡さなければならない。
- AC-7: IF 除外の一覧にある防具を部位の固定で選んだとき、または固定している防具を除外の一覧に足したとき THEN システムは、後の操作を優先し、前の指定（除外の一覧のその防具、またはその部位の固定）を解除しなければならない。ソルバーに固定と除外の両方を同じ防具で渡してはならない。
- AC-8: THE system SHALL 検索の前に、検索条件の欄で、固定している部位と除外している防具・装飾品が分かるように表示し、結果の検索条件の要約にも、固定した部位の数と除外した防具・装飾品の件数を示さなければならない。
- AC-9: WHEN 固定か除外を指定した検索で条件を満たす構成が見つからなかったとき THE system SHALL 解なしの案内に「部位の固定や除外を減らす」旨を加えなければならない。固定も除外も無い検索の案内は変えてはならない。
- AC-10: THE system SHALL 部位の固定と除外の一覧を端末に保存せず、再読み込みの後は既定（固定なし・除外なし）にしなければならない（decisions.md Q81）。
- AC-11: THE system SHALL Playwright（Chromium）の e2e テストで、「頭を防具に固定すると、結果のどの構成も頭がその防具になる」「部位を何も付けないにすると、結果のどの構成もその部位が空になる」「除外した防具・装飾品が、結果のどの構成にも出ない」ことを検証しなければならない。

## スコープ外
- 検索結果の構成のカードからの固定・除外の操作（decisions.md Q82）
- 固定・除外の端末への保存と、ログインユーザーのサーバーへの保存（decisions.md Q81）
- シリーズやランクの単位でまとめて除外すること（ランクは 004 の「候補にするランク」のまま）
- 装飾品の固定（使う装飾品や、装飾品を入れるスロットを指定すること）
- 護石・武器の除外（護石は 021 の生産護石の切り替えと 005 の登録で扱う）
- 検索画面のレイアウトの変更（open-questions.md Q28）

## 契約差分
- なし（API を変えない。構成の保存の契約は検索条件を持たないので、`BuildPayload` も変えない）
