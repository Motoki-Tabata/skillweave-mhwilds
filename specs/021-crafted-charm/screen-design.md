## 0. 前提

- 生産護石は、防具と同じく、すべて持っているとみなす。系統ごとの所持の入力と保存はしない（decisions.md Q31）。
- 候補にする生産護石は、系統ごとに最上位ランクの1件だけ。マスター 2026.10.4 では 60 件（decisions.md Q77）。
- 鑑定護石か生産護石かは、護石の ID が `ch:` で始まるかどうかで見分ける（decisions.md Q31）。
- 生産護石を使った構成は保存できない（decisions.md Q78。保存は 027）。
- 検索画面のレイアウト（カードの並び・ブレークポイント）は変えない（open-questions.md Q28）。
- 追加する ui 部品は無い（既存の `card`・`checkbox`・`label`・`button`・`alert` で足りる）。

## 2. S1 検索画面（変更）

### 2.1 「護石」カード

並び（上から）: 見出し h2「護石」 → 生産護石の切り替え → 鑑定護石の件数（状態ごと） → 「護石の一覧へ」（005 のまま）。

```
護石
[✓] 生産護石を候補に含める
    素材で作れる護石を、すべて持っているとみなして候補にします（系統ごとに最上位ランクの 60 件）。
候補にする鑑定護石: 3 件
[護石の一覧へ]
```

切り替え:

| 項目 | 内容 |
|---|---|
| 部品 | `Checkbox` と `Label` の行（高さ 44px。検索条件カードの「候補にするランク」の行と同じ形） |
| ラベル | 「生産護石を候補に含める」（14px） |
| 補助テキスト | 行の下に 12px・`--muted-foreground` で「素材で作れる護石を、すべて持っているとみなして候補にします（系統ごとに最上位ランクの <K> 件）。」。K はマスターから求めた件数（Inter・`tabular-nums`）。`aria-describedby` でチェックボックスに関連づける |
| 既定 | オン |
| 状態の保持 | 検索条件と同じく、画面を移っても（S1 ⇄ S2）残すが、端末には保存しない。再読み込みするとオンに戻る |
| 操作できないとき | 無い。鑑定護石の読込中・読込失敗のときも操作できる |
| 検索との関係 | 送信した時点の値で候補を決める。検索の後に切り替えても、表示中の結果と要約は変えない |

鑑定護石の件数（005 の 2.3 の表を置き換える。文言の後半は切り替えに応じて変える）:

| 状態 | 切り替えオン | 切り替えオフ |
|---|---|---|
| 読込中 | 300ms 未満は何も出さない。超えたら「護石を読み込んでいます…」（`<output>`） | 同左 |
| 候補が1件以上 | 「候補にする鑑定護石: <N> 件」（N は Inter・`tabular-nums`）。検索対象外の補助文は 005 のまま（「登録した <M> 件のうち <K> 件は、…」） | 同左 |
| 登録が0件 | 「鑑定護石が登録されていません。生産護石だけを候補にして検索します。」 | 「鑑定護石が登録されていません。護石なしで検索します。」 |
| 読込失敗（読み込めない・端末に保存できない） | 警告の帯「護石を読み込めませんでした（<原因>）。生産護石だけを候補にして検索します。」 | 警告の帯「護石を読み込めませんでした（<原因>）。護石なしで検索します。」 |

- 検索は止めない（005 のまま）。読込失敗のときは、切り替えがオンなら生産護石だけを、オフなら護石なしで解く（AC-6）。

### 2.2 検索条件の要約

- 「／ 護石 <N> 件」を「／ 鑑定護石 <N> 件 ／ 生産護石を含める」（オフのときは「生産護石を含めない」）に変える。N は送信した時点の鑑定護石の候補の件数。
- 例: 「武器: … ／ 必須スキル 2 件 ／ 火力の最大化 ／ 10 件まで ／ 鑑定護石 3 件 ／ 生産護石を含める ／ 発動条件: なし」
- 要約は今のとおり折り返す（`break-words`）。

### 2.3 構成のカードの護石の節

節を出す条件を「送信した時点の鑑定護石の候補が1件以上、または生産護石を含めた」に変える（どちらも無いときは節ごと出さない。どちらかがあり、構成が護石を使っていないときは「護石なし」）。

生産護石を使った構成（`charmId` が `ch:` で始まる）:

```
護石
  名前      耳栓の護石Ⅱ
  レア度    7
  スキル    耳栓 Lv2
  スロット  スロットなし
```

| 項目 | 内容 |
|---|---|
| 名前 | 先頭の行。ラベル「名前」（12px・幅 56px。ほかの行と同じ）、値は ja の辞書の名前（14px）。辞書に無いときは ID をそのまま出す（マスターの不整合。通常は起きない） |
| レア度・スキル・スロット | 鑑定護石と同じ（005 の 2.3）。値はマスターの生産護石から引く |
| 装飾品の表・空きスロット | 持ち主は「護石」のまま（005 の 2.3） |

- 鑑定護石を使った構成の表示は変えない（「名前」の行を出さない。AC-7）。

### 2.4 生産護石を使った構成のカードの「保存」

検索が終わった後の結果（011 の 3.1 で「保存」を出すカード）のうち、生産護石を使った構成だけを次のようにする。

| 項目 | 内容 |
|---|---|
| 「保存」のボタン | 出さない（無効にして置くこともしない）。見出しの行は、期待値・防御力だけになる |
| 理由の表示 | 見出しの行の直下、火力の節の上に、補助テキスト（12px・`--muted-foreground`）で、lucide `Info`（16px・`aria-hidden`）と「生産護石を使った構成は保存できません。」を並べる |
| 検索中に見つけた順に出すカード（011 の 3.1 で「保存」を出さないカード） | 理由も出さない（ほかのカードと同じく「保存」に関わる表示を出さない） |

- 鑑定護石を使った構成と、護石なしの構成は、011 のまま「保存」を出す（AC-8）。

### 2.5 幅の見積もり（S1。最小幅 360px）

文字幅の概算は 004 の 3.6 と同じ（日本語 1 字 = 文字サイズ、英数字 ≈ 文字サイズ × 0.55）。カードの内幅 約 294px。

| 箇所 | 並べる要素 | 最小幅の合計 | 判定と扱い |
|---|---|---|---|
| 「護石」カードの切り替えの行 | チェックボックス（16）＋間隔 8＋「生産護石を候補に含める」（11字×14＝154） | 約 178 | 収まる |
| 切り替えの補助テキスト | 12px・約 45 字 | 約 540 | 折り返す（2行。左端はラベルにそろえる） |
| 構成のカードの「名前」の行 | ラベル（56）＋間隔 8＋最長の名前「にぎりめしの護石」（8字×14＝112） | 約 176 | 収まる |
| 保存できない理由の行 | アイコン（16）＋間隔 4＋「生産護石を使った構成は保存できません。」（19字×12＝228） | 約 248 | 収まる（1行） |
| 構成のカードの見出しの行（「保存」なし） | 「構成 10」（約 60）＋期待値・防御力（約 100）＋間隔 8 | 約 168 | 収まる |

### 2.6 キーボード・フォーカス・読み上げ

- 切り替えは Tab で止まり、Space で切り替わる（`Checkbox` の既定）。ラベルを押しても切り替わる。
- 補助テキストは `aria-describedby` で読み上げる。
- 保存できない理由は、ボタンではなく文として置く（フォーカスは止まらない）。カードの見出しの直後にあるので、カードを読み進めると読み上げられる。
