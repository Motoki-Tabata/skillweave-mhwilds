## 2. D2 スキルを選ぶダイアログ（変更）

### 2.1 画面構成

検索語が空のとき（基準幅。`md` 以上は一覧の格子の列数だけが増える）:

```
スキルを選ぶ                                  [×]
押すと必須スキルに追加し、もう一度押すと外します。…
[ 検索欄                                      ]
[ 武器 | 防具 | シリーズ | グループ ]
■ 攻撃 ────────────────────────
[ [攻撃のスキルA]        ] (i)
[ [攻撃のスキルB]  選択中 ] (i)
■ 会心 ────────────────────────
[ [会心のスキルA]        ] (i)
  …
■ 属性・状態異常 ───────────────
  …
├ フッター（固定）──────────────
選択中のスキル（1）
武器 [攻撃のスキルB]
[ 閉じる ]
```

検索語があるときは、今のまま（タブも見出しも出さず、件数の行と一覧だけ）。

### 2.2 分類の見出し

| 項目 | 内容 |
|---|---|
| 要素 | `<h3>`（ダイアログの題が h2。フッターの「選択中のスキル」と同じ階層）。フォーカスは持たない。押しても何も起きない |
| 見た目 | MASTER.md の「小見出し（刻印風）」: 12px・700・字間 0.12em・`--muted-foreground`。文言の左に 6px 四方の `--primary` の角、右に残りの幅いっぱいの 1px の `--border` の線 |
| 文言 | 表示の順に「攻撃」「会心」「属性・状態異常」「斬れ味」「武器種固有」「防御・回復」「耐性」「行動・スタミナ」「探索・支援」。件数は出さない |
| 順 | 上の順で固定する。どのタブでも同じ |
| 出さないとき | そのタブの種類に、その分類のスキルが 1 件も無いとき（AC-8）。空の見出しも詰め物も出さない |
| 固定 | しない。見出しは一覧と一緒にスクロールする |

間隔: 見出しとその下の一覧は 8px、分類のかたまりどうしは 16px（MASTER.md の Density）。タブと最初の見出しのあいだは、今のタブと一覧の間隔のまま。

### 2.3 見出しの下の一覧

- 今のスキルの一覧の部品をそのまま使う（トグルボタンと説明のボタンの行。高さ 44px 以上。基準幅で 1 列、`md` で 2 列、`lg` で 3 列）。格子は分類ごとに区切る。
- 並びは、今のタブの中と同じ ja の名前順（AC-7）。
- 説明を開く: 押した行の次に、幅いっぱいの説明の領域を出す（今のまま）。分類をまたいでも、開くのはダイアログ全体で 1 つだけ。別の分類の説明を開くと、先に開いていた説明は閉じる（AC-10）。

### 2.4 状態

| 状態 | 表示 |
|---|---|
| 検索語が空 | 見出しで区切った一覧（2.1） |
| 検索語がある | 見出しの無い一覧（種類の順、種類の中は名前順。種類名を右に出す）。今のまま（AC-9） |
| 検索語を消す | 見出しで区切った一覧に戻る。タブは検索の前に選んでいたもののまま（今のまま） |
| タブの切り替え・検索語の変更 | 開いている説明を閉じる（今のまま） |
| スキルを押す | 必須スキルへの追加・削除と、「選択中」・フッターの表示。今のまま（AC-10） |

### 2.5 幅の確認（最小対応幅 360px）

ダイアログの本文の幅は 328px（360px から左右の余白 16px を引く）。見出しの行は、角 6px・間隔 8px・文言・間隔 8px・線で、最も長い文言（「属性・状態異常」「行動・スタミナ」の 7 文字）は 12px × 7 と字間で約 95px なので、線に約 210px 残る。切り詰めは要らない。

### 2.6 読み上げとキーボード

- 見出しは `<h3>` なので、見出しの移動で分類へ飛べる。Tab の移動先は増えない（見出しはフォーカスを持たない）。
- 情報を色だけで伝えない: 分類は文言で示す。角と線は飾りで、`::before`・`::after` か `aria-hidden` にする。
