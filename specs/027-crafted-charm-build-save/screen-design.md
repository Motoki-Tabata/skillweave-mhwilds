## 0. 前提

- 生産護石を使った構成も、鑑定護石を使った構成と同じく保存できる（AC-5）。021 の 2.4（「保存」を出さずに理由を出す）を取り消す。
- 生産護石は ID の参照だけを保存し、写しは持たない。保存した構成の画面（S5）では、護石の名前・レア度・スキル・スロットを、開いたときのマスターと辞書から ID で引く（decisions.md Q93）。
- マスターの版が保存したときと違う旨は、既存の版の違いの警告（011 の 5.3）に任せる。027 で警告の文言は変えない。
- 鑑定護石か生産護石かは、021 と同じく護石の ID が `ch:` で始まるかどうかで見分ける（S5 では保存した `charm` の形で見分ける）。
- 画面の追加・遷移の変更・ui 部品の追加は無い。S4（保存した構成の一覧）の行は護石を出さないので変えない。

## 2. S1 検索画面（変更）

### 2.1 構成のカードの「保存」

- 検索が終わった後の結果（011 の 3.1 で「保存」を出すカード）では、護石が生産護石・鑑定護石・護石なしのどれでも、011 の 3.1 の「保存」を出す（置き場・形・押したとき・判定中・保存した後のすべて 011 のまま）。
- 021 の 2.4 の理由の表示（lucide `Info` と「生産護石を使った構成は保存できません。」）は出さない（AC-5）。
- 検索中に見つけた順に出すカードは、011 のまま「保存」を出さない。
- 未ログイン・取得できないときに「保存」を押すと、011 のまま D6 を開く（AC-5）。

### 2.2 幅の見積もり

- 見出しの行は、鑑定護石を使った構成と同じ並び（「構成 10」・期待値・防御力・「保存」）になる。011 の 3.2 の見積もり（約 220px／内幅 294px）のとおり収まる。
- 理由の行が無くなる分、カードの高さが1行ぶん縮む。ほかの行の幅は変わらない。

## 3. S5 保存した構成（変更）

### 3.1 構成のカードの護石の節

011 の 5.4 の表の「護石」の行を、次に置き換える。

| 項目 | 検索結果 | S5 |
|---|---|---|
| 護石 | 検索したときの候補から引く。候補が0件で、生産護石も含めない検索では節ごと出さない | 鑑定護石は保存した写しを使う。生産護石は保存した ID で現在のマスターと辞書から引く。護石を使わない構成は、節を出して「護石なし」 |

生産護石を使った構成（現在のマスターに ID があるとき。AC-7）:

```
護石
  名前      耳栓の護石Ⅱ
  レア度    7
  スキル    耳栓 Lv2
  スロット  スロットなし
```

- 並び・部品・文字の大きさは、検索結果の構成のカードの生産護石（021 の 2.3）と同じにする。名前は ja の辞書の名前、レア度・スキル・スロットは現在のマスターの生産護石の値。
- 護石のスキルが現在のマスターに無いときは、011 の 6.5 のとおりチップに「不明なスキル（<ID>） Lv<n>」を出す。
- 装飾品の表・空きスロットの持ち主は「護石」、スロットの Lv は現在のマスターの生産護石から引く。
- 鑑定護石を使った構成の表示は、011 の 5.4 のまま変えない（「名前」の行を出さない。AC-4）。

### 3.2 現在のマスターに無い生産護石（AC-8）

011 の 6.5 の表に、次の行を足す。

| 対象 | 表示 |
|---|---|
| 生産護石 | 護石の節の「名前」の値に「不明な護石（<ID>）」、「レア度」「スキル」「スロット」の値に「−」。装飾品の表で持ち主が「護石」の行のスロットは「−」、空きスロットの護石のチップは「−」 |

```
護石
  名前      不明な護石（ch:-1137475456:3）
  レア度    −
  スキル    −
  スロット  −
```

- 「スキルなし」「スロットなし」とは書かない（分からないのであって、無いのではないため）。
- 防具・装飾品・発動スキル・空きスロット・火力は、011 のまま表示する（AC-8）。発動スキルと火力は保存した値から求めるので、護石が引けなくても変わらない。
- `<ID>` は保存した文字列のまま（Inter にしない）。色は変えない（`--foreground`。011 の 6.5）。
- マスターの版の警告（011 の 5.3）は、版が違うときだけ出す。生産護石が引けないことを理由に別の警告は出さない。

### 3.3 幅の見積もり（S5。最小幅 360px）

文字幅の概算は 004 の 3.6 と同じ（日本語 1 字 = 文字サイズ、英数字 ≈ 文字サイズ × 0.55）。カードの内幅 約 294px。

| 箇所 | 並べる要素 | 最小幅の合計 | 判定と扱い |
|---|---|---|---|
| 「名前」の行（生産護石） | ラベル（56）＋間隔 8＋最長の名前「にぎりめしの護石」（8字×14＝112） | 約 176 | 収まる（021 の 2.5 と同じ） |
| 「名前」の行（不明な護石） | ラベル（56）＋間隔 8＋「不明な護石（」「）」（7字×14＝98）＋ID 約 16 字（16×14×0.55≈123） | 約 285 | 収まるが余裕が少ない。系統の数値の桁が増えたときは、値の側だけを折り返す（`break-words`。いまの「名前」の行のまま） |
| 「レア度」「スキル」「スロット」の行（不明な護石） | ラベル（56）＋間隔 8＋「−」 | 約 78 | 収まる |

### 3.4 キーボード・フォーカス・読み上げ

- 変えない。護石の節は文として読み上げる（「名前 不明な護石（ch:…）」「レア度 −」）。「−」は読み上げで「マイナス」と読まれることがあるが、防具の防御力・装飾品のスロットの「−」（011 の 6.5）とそろえる。
