### 項目定義（表記の文面）
事実の正は decisions.md の Q141 の表。変える節だけを書き、他の節の文面は変えない。

**アクセス解析**（AC-1〜AC-5）

アクセス数と表示の速さを知るために、Cloudflare Web Analytics を使っています。

ブラウザは、開いたページの URL と読み込みの時間などの計測値を Cloudflare へ送ります。この通信でも IP アドレスが Cloudflare に届きます。Cloudflare は、国・ページのパス・参照元・ブラウザ・OS・端末の種類を集計します。

Cloudflare の説明では、この計測に Cookie と localStorage を使いません。詳細なデータは 7 日間保持され、その後は約 10% に集約されます。詳しくは [Cloudflare Web Analytics の説明] を確認してください。

**Cookie**（AC-6）

- `SESSION`: ログインの維持
- `XSRF-TOKEN`: 不正な要求の防止

広告は入れていません。

**アクセスログ**（AC-7）

Cloudflare と Google Cloud のアクセスログに、IP アドレス・User-Agent・参照元・要求の URL などが記録されることがあります。Google Cloud のログの保持期間は、既定で 30 日です。Cloudflare の処理については、[Cloudflare のプライバシーポリシー] の「End Users」の項を確認してください。このポリシーは個々のサイトの扱いを定めるものではありません。

**最終更新日**（AC-8）

形式は `YYYY/MM/DD`。値は文面を変えた日にする（実装のときに決める）。

### 書かないこと
- IP アドレスの保存の有無（Web Analytics について）とクエリ文字列の扱い（AC-3）
- Cloudflare のアクセスログの保持期間（AC-7）
- 「アクセス解析に〜を使っています」の形の文。この画面の本文は「解析に使う」「解析に利用する」の形を、Google の用途を断定しないために避けている（`PrivacyView.spec.ts` の AC-3 が検査する）。

## テストへの影響（区間 D で扱う）
- `PrivacyView.spec.ts` の AC-10 のテストは、節の本文を「を確認してください」までで切り出す。新しい文面もこの語で終わるので切り出しは動くが、「Cloudflare での扱いは」を確かめている行は新しい導入文に直す。
- 同じテストの「数字が無い」の検査は、切り出しの範囲がアクセスログの節の中で終わるので、アクセス解析の節の「7 日間」「約 10%」には当たらない。
