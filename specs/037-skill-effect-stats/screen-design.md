## 2. 補完の書式（007 §4 の表に足す）

既存の 6 行（`attack_add`・`attack_mul`・`affinity_add`・`crit_mul`・`element_add`・`element_mul`）の書式は変えない。下の表の「<区別>」は種類の区別の表示名で、区別が「武器の属性（状態異常）を問わない」効果は「<区別>」を付けない。

| 種類 | 加算・乗算 | 書式 | 例 |
|---|---|---|---|
| 属性値 | 加算 | <区別>値 <符号><表示値> | 火属性値 +60（区別なし: 属性値 +60） |
| 属性値 | 乗算 | <区別>値 ×<値（小数第2位）> | 火属性値 ×1.20（区別なし: 属性値 ×1.20） |
| 状態異常値 | 加算 | <区別>値 <符号><表示値> | 毒属性値 +50（区別なし: 状態異常値 +50） |
| 状態異常値 | 乗算 | <区別>値 ×<値（小数第2位）> | 毒属性値 ×1.20（区別なし: 状態異常値 ×1.20） |
| 属性の会心倍率 | 最大を採る | 属性の会心倍率 <値（小数第2位）> | 属性の会心倍率 1.35 |
| 状態異常の会心倍率 | 最大を採る | 状態異常の会心倍率 <値（小数第2位）> | 状態異常の会心倍率 1.20 |
| 防御力 | 加算 | 防御力 <符号><値> | 防御力 +35 |
| 防御力 | 乗算 | 防御力 ×<値（小数第2位）> | 防御力 ×1.10 |
| 耐性値 | 加算 | <区別>耐性 <符号><値> | 火耐性 +20・全属性耐性 +5 |

種類の区別の表示名:

| 種類 | 区別 | 表示名（「<区別>」に入る文字） |
|---|---|---|
| 属性値 | 火・水・雷・氷・龍 | 火属性・水属性・雷属性・氷属性・龍属性 |
| 属性値 | 武器の属性を問わない | （付けない。「属性値」） |
| 状態異常値 | 毒・麻痺・睡眠・爆破 | 毒属性・麻痺属性・睡眠属性・爆破属性 |
| 状態異常値 | 武器の状態異常を問わない | （付けない。「状態異常値」） |
| 耐性値 | 火・水・雷・氷・龍 | 火・水・雷・氷・龍 |
| 耐性値 | 全属性 | 全属性 |

- 属性値・状態異常値の表示名は、武器の属性の種類の表示名（`apps/web/src/main/constants/weapons.ts` の `ELEMENT_TYPES`）と同じ文字にする。耐性値の表示名は、ゲーム内の説明文（「火耐性＋２０」「全属性耐性値＋５」）と防具の耐性の呼び方に合わせ、「値」を付けない。
- 表示値: 属性値・状態異常値の加算だけ、マスターの値 × 10 を出す。浮動小数の誤差を出さないため、× 10 の結果を整数に丸める（マスターの単位の小数第1位が表示値の1の位に当たる）。他の種類の加算は、007 のとおり丸めずに出す。
- 乗算・会心倍率の値は、007 のとおり小数第2位で出す（例: 1.1 → `1.10`）。
- 符号・数字の書体（Inter・`tabular-nums`）・発動条件の組・組の区切り（「・」と「 ／ 」）・組の順（最初に出た順）・効果が無いレベルでは出さないことは、007 §4 のまま。
- 同じレベルの効果の並びは `effectsByLevel` の順のまま出す。overlay は説明文に出てくる順（乗算 → 加算 → 他の種類）に書く（区間 C の overlay の作業で守る）。
- 属性の会心倍率・状態異常の会心倍率は、037 では値を持つスキルが無いので画面に出ない（値は 038 で入れる）。書式は 038 が overlay に値を書くだけで出るように、037 で用意する。
- `element_add`・`element_mul`（007 の書式「属性値 …」）を、037 の属性値の種類に置き換えるか残すかは区間 C で決める。どちらにしても、区別が無い属性値の効果は上の表の「区別なし」の書式（`element_mul` と同じ「属性値 ×<値>」）で出す。`element_add` の値の単位を変えるなら、表示値（× 10）の規則も同じに揃える。
